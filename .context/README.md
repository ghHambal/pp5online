# Shared AI Context — ปพ.5 ออนไลน์

ไฟล์ในโฟลเดอร์นี้ใช้เพื่อให้ Claude และ Codex อ่าน/เขียนร่วมกัน
เพื่อให้ทั้งสองรู้บริบทโปรเจกต์แม้ขึ้น session ใหม่

## วิธีใช้

- **เมื่อเริ่ม session ใหม่**: อ่านไฟล์ทั้งหมดในโฟลเดอร์นี้ก่อนเสมอ
- **เมื่อจบ session**: อัปเดตตามที่ผู้ใช้สั่ง "อัปเดตความจำ" หรือยืนยันเมื่อถูกถาม
- **การอัปเดต**: แก้เฉพาะส่วนที่เปลี่ยนไป ไม่ต้องเขียนใหม่ทั้งหมด

## ไฟล์

| ไฟล์ | เนื้อหา |
|---|---|
| `project-state.md` | สถานะโปรเจกต์, stack, โครงสร้างไฟล์ |
| `recent-session.md` | สิ่งที่ทำใน session ล่าสุด |
| `decisions.md` | การตัดสินใจด้าน design สำคัญ |
| `pending-tasks.md` | งานค้าง, TODO, สิ่งที่รอ spec |

## คำสั่งพิเศษ

ผู้ใช้พิมพ์ "**อัปเดตความจำ**" → AI อัปเดตไฟล์ทั้งหมดแล้วถามยืนยันก่อน commit
