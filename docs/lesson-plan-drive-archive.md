# จัดเก็บแผนการสอนรายสัปดาห์เข้า Google Drive

ระบบจะรวบรวมแผนที่บันทึกผลหลังสอนครบ 3 ลายเซ็น แยกตามห้องเรียนและวันที่สอน แล้วสร้าง PDF เดียวต่อรายวิชา/สัปดาห์ ผ่านเมนู `🗂️ จัดการแผนทุกห้องในคอร์ส / ส่งเข้า Drive` ในแท็บแผนการสอนของ Smart Classroom หรือเมนูจัดเก็บในหน้าออกแบบการสอนของคอร์ส

## โครงสร้าง Drive

โฟลเดอร์หลักส่วนตัวของครู → `สัปดาห์ที่ N` → `ครูชื่อและนามสกุล` → PDF รายวิชา

การตั้งค่าเป็นรายครูและรายภาคเรียน ไม่ใช้โฟลเดอร์กลางร่วมกัน ครูตั้งค่าได้จากหน้าศูนย์ส่ง/จัดเก็บแผนรายสัปดาห์ในหน้ารายวิชา:

- `Folder ID` ของโฟลเดอร์หลักส่วนตัว
- กลุ่มสาระที่ต้องการตรวจสอบ (ถ้ามี)
- สร้างโฟลเดอร์สัปดาห์/ครูอัตโนมัติได้หรือไม่
- แทนที่ไฟล์ชื่อเดิม หรือเก็บเป็นไฟล์เวอร์ชันใหม่

ระบบบันทึกค่าแยกด้วย `teacher_id + academic_year + semester` และ Edge Function จะอ่านเฉพาะค่าของเจ้าของรายวิชา จึงไม่สามารถส่งไฟล์ไปยังโฟลเดอร์ส่วนตัวของครูคนอื่นได้

## Central GAS

ต้องนำ `gas/pp5-sync.gs` เวอร์ชันเดียวกับ release นี้ไปวางในโปรเจกต์ Central GAS แล้ว Deploy → New version ของ Web app เดิม โดยคง URL เดิมไว้ ระบบจะตรวจ `lesson_plan_archive_capabilities` ก่อนส่งไฟล์ทุกครั้ง หากยังเป็นรุ่นเก่าจะหยุดและแจ้งให้ Deploy ก่อน จึงไม่เกิดการส่งไฟล์แบบไม่รู้ผล
