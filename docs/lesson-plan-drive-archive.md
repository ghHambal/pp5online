# จัดเก็บแผนการสอนรายสัปดาห์เข้า Google Drive

ระบบจะรวบรวมแผนที่บันทึกผลหลังสอนครบ 3 ลายเซ็น แยกตามห้องเรียนและวันที่สอน แล้วสร้าง PDF เดียวต่อรายวิชา/สัปดาห์ ผ่านเมนู `📦 ส่ง/จัดเก็บรายสัปดาห์` ในหน้าออกแบบการสอนของคอร์ส

## โครงสร้าง Drive

โฟลเดอร์หลักภาคเรียน → `สัปดาห์ที่ N` → `ครูชื่อและนามสกุล` → PDF รายวิชา

ตั้งค่าได้ที่ Admin → ตั้งค่าระบบ → Sync Engine:

- `lessonPlanDriveDeptCode` เช่น `MATH`
- `lessonPlanDriveRootId` เช่น `1u9ZGSOBbaIImdOrBuL4crGTJnsCRPaoq`
- สร้างโฟลเดอร์อัตโนมัติได้หรือไม่
- แทนที่ไฟล์ชื่อเดิม หรือเก็บเป็นไฟล์เวอร์ชันใหม่

## Central GAS

ต้องนำ `gas/pp5-sync.gs` เวอร์ชันเดียวกับ release นี้ไปวางในโปรเจกต์ Central GAS แล้ว Deploy → New version ของ Web app เดิม โดยคง URL เดิมไว้ ระบบจะตรวจ `lesson_plan_archive_capabilities` ก่อนส่งไฟล์ทุกครั้ง หากยังเป็นรุ่นเก่าจะหยุดและแจ้งให้ Deploy ก่อน จึงไม่เกิดการส่งไฟล์แบบไม่รู้ผล
